# Kujo68K

Cycle-accurate M68000 emulation library, kinda

A (WIP) cycle-accurate emulation library for the M68000 processor, writen in C++20.

## Features

Platform-independent and architecture-independent code

Derived from the original M68000 microcode

Clock-cycle ticked emulation (inspired by the [chips emulation project](https://github.com/floooh/chips/tree/master))

And more to come!


# Plans

## Near-term

Thoroughly verify interrupt-related functionality and bus arbitration logic (basic tests of both confirmed working)

## Medium-term

Implement bus-error and address-error logic

## Long-term

M68008 support

Support for other (M68000-derived) variants (such as TMP68301, and possibly others)
